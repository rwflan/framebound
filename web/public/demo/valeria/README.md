# Valeria movement proof assets

This demo uses the playable 2D Valeria runtime and authored movement states from
the local, public `castlevania-saeculum-obscurum` project. The proof is kept
inside Framebound's existing utility window; it does not create a second review
workflow.

| Asset | Purpose |
| --- | --- |
| `raw-muse-sheet.png` | One direct `muse-image-1.0` output. It is an opaque 3 × 3 contact sheet produced without Framebound registration, extraction or scoring. The exact provider request and response receipt remain outside this checkout. |
| `refined-atlas.png` | The registered RGBA pose atlas. It uses the approved standing authority and the project's authored native movement timing. |
| `refined-meta.json` | A reduced runtime copy containing only frame regions, pivots, trim data and pixel scale. Authoring prompts and receipts are not copied. |
| `playback.json` | Valeria's runtime states and authored holds. |
| `manifest.json` | The frozen facts rendered by the proof, including the direct output SHA-256. |

The direct control cost $0.01. The comparison demonstrates delivery readiness:
transparent extraction, one native canvas, stable registration, explicit holds
and a complete movement state machine. It does not assert that an automated
aesthetic review has declared the refined art superior.
