# Repository instructions

- New code changes belong on their own `codex/` branch. Open a remote pull request, pass required checks, then merge to main. Resolve conflicts.
- Before changing the app UI, read `web/public/designs/posthog/DESIGN.md` and `docs/DESIGN.md`. Reuse the existing shell, navigation, queue, film and frame windows. Interventions is the single feedback/review workflow. Do not add a separate studio, duplicate navigation or sidebar promotional links.
- The MVP is isolated 2D characters, animals, figures and objects with real transparent surroundings. Intake precedes animation assessment; backgrounds, paper, scenes and effects-only sequences are excluded. Preserve originals and receipts; never relabel an isolation pass as semantic quality, human acceptance or training readiness.
- Private artwork, prompts, annotations, receipts, credentials and experiment data stay outside Git. Unknown provider acceptance is never resubmitted under the same operation and committed spend is never reset. Resume accepted requests by their retained provider ID. When the user has authorized recovery and a private run policy records its budget, create a distinct linked successor within that budget, retain the unknown parent and its commitment, and continue without asking for the same authorization again.
