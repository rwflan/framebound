# Optional model training

Ordinary animation generation uses the MCP harness workflow and packaged
animation guidance. Training is an advanced option for consistency models over
numeric animation features, not an image-generator fine-tuning service.

Open the existing workspace menu and choose **Train a model**. The guided flow
connects Meta and Modal, collects a name, learning focus and spending ceiling (up
to $50 per journey), and shows the
standard quote before an explicit paid start. Meta supplies pose screens,
whole-screen segmentation and independent assessments. Modal requires its token
ID and token secret; a token alone is not proof of available credit.

Both connections can also be replaced or disconnected independently in
**Settings**. Secrets are write-only from the browser, stored in a private local
directory with restrictive permissions, and never included in exports or public
status. `FRAMEBOUND_TRAINING_HOME` can relocate that directory outside the source
checkout. Browser forms clear saved credentials and do not use local storage.

The journey preserves a fixed rehearsal cohort, then a gated pilot and bounded
coverage expansion. Generation uses full pose screens with one whole-screen
mask, followed by local cutting and assembly. Pausing drains admitted work;
restarting the app resumes the saved cohort and retrieves accepted responses.
Unknown provider acceptance never triggers another creation request. Incurred
costs and outstanding reservations count toward the ceiling.

Progress distinguishes collection from trainability. Real local training needs
300 distinct training sequences, 75 families and scoped positive/negative support
for every advertised category. Models, calibration and evaluation remain
unpromoted until their release gates pass. Technical alpha extraction and a
successful collection batch never establish artistic acceptance.

The focus selects the categories studied and advertised by the trained model;
it does not fabricate category labels or change acquisition gates. The progress
window shows actual per-category sequence/family/positive/negative support. Once
supported local fitting completes, download the model card and six checkpoints
from that window.

Remote compute additionally requires verified applicable credit, current pricing,
a transfer-safe numeric feature shard and a matching measured profile. The
existing profile/train/reproduce gates and cost caps apply. Credentials do not
authorize uncovered charges or justify using a GPU when local work is faster.
The optional compute panel asks for the current applicable credit, workspace
allowance, expiry and evidence source, resolves a pinned worker image, and
requires an explicit capped start. It performs profile → train → reproduction
only while the existing gates pass, retaining the local model when the measured
speedup is insufficient.

## Combining existing evidence

`framebound.v3.campaign.pooling.build` takes explicit closed source snapshots and
publishes a new immutable pooled dataset. It validates each source and authentic
received generation/assessment evidence, preserves splits and label scope,
quarantines unknown ancestry and cross-split visual leakage, and deduplicates
timed sequences. Source studies keep their original outcomes and stage gates.
No failed campaign is retrospectively declared passed. Validation examples do
not become training examples, and cropped frames do not become independent
training sequences. Private corpus, reports and derived models stay outside Git.

The default packaged guidance consists of generalized authored principles,
not copied private prompts, images, annotations or receipts. Historical model
assessments remain advisory evidence rather than human ground truth.
