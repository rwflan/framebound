# Valeria movement proof

Open `http://127.0.0.1:5173/#/valeria-demo` after starting the local desk. The
same utility is available as **Valeria movement** in the `•••` workspace menu.

The playfield has two outputs:

- **Direct Muse** displays one opaque, provider-authored 3 × 3 run contact
  sheet. Its request, response and receipt remain outside this checkout.
- **Framebound** uses Valeria's registered RGBA atlas, the approved standing
  authority and nine authored run keys with their native holds. It also has
  idle, jump, apex, fall, slide and attack states.

Use the arrow keys or the visible left/right buttons to move. Press or click
**Space** to jump, **S** to slide and **J** to attack. **Compare** controls both
models with the same input; **Framework** and **Direct Muse** isolate one side.

The proof demonstrates delivery preparation: extraction, stable registration,
a native canvas and authored playback. It does not claim that automated scoring
has established an aesthetic win over direct Muse generation.
