# Demo script (adapt to the portal's verified duration limit)

Badges on screen at all times: `[replay/procedural-original]` until a live provider run lands.

1. **Problem (30 s).** Solo dev needs one character consistent across hundreds of AI-assisted frames.
   Show Pip reference sheet (`character/identity.png`) vs a visibly inconsistent run.
2. **Loop (60 s).** Spark uses typed tools; Muse Image request carries real reference pixels + roles
   (show `fixtures/provider-spike/image-generation.json` when live; today: offline request artifact,
   `not_configured`, nothing fabricated). Framework catches a local pulse + wrong phase.
3. **Repair (45 s).** Bounded repair at normal speed; inspect one protected contact + coverage report.
   Before/after at identical timing.
4. **Human round-trip (60 s).** Mark an ROI issue across frames 3–5 → correction task appears in the model
   queue → tool client claims, submits a passing replacement → compare revisions → resolve that issue.
   Reload the browser mid-way to prove persistence.
5. **Export (45 s).** Move the snapshot to a new directory; load it with `datasets` + COCO in front of the
   camera. Show one chosen/rejected pair with original conditioning, timing, and label provenance.
6. **Scope (20 s).** What shipped: 4 clips, 3 transitions, honest partial coverage on jump occlusion,
   training objective (fewer defects, less review). Replay labels stay visible; no live claim.

Screen text stays functional: action, revision, phase, measured defect, coverage, decision.
